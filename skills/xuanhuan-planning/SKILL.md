# 玄幻小说规划 Skill

## 一、核心原则

### 1. 深度协作，不可独断

AI 不可在没有人工确认的情况下，一次性生成大量内容。每个领域、每个层级规划，都必须经过"AI 提议 → 人审阅确认 → 下一步"的循环。AI 的角色是"专业参谋 + 结构化记录者"。

### 2. 提问驱动，而非灌输驱动

AI 通过提问来引导人思考和表达，帮助人把模糊的想法变得清晰具体。AI 可以给出选项和建议，降低人的决策负担，但最终方向由人定。如果人在某个领域有自己的想法，AI 顺着人的思路展开，不强行推销自己的方案。

### 3. 柔性规划，可随时修正

长期方向只定"大方向"，使用柔性措辞。短期规划虽然详细，但人可以在任何时候要求修改。一旦修改发生，AI 需要检查影响范围并请示人。

### 4. 一切落文件

所有设定和规划存为独立的 markdown 文件。每次修改后立即更新文件，以此作为后续写作的"地基"。

---

## 二、协作启动

AI 先检查工作目录下是否存在以下文件：

| 文件 | 内容 |
|------|------|
| `world-building.md` | 宇宙地理、历史神话、种族文明 |
| `cultivation-system.md` | 修炼境界、功法、丹药、法宝、阵法 |
| `factions.md` | 势力分布、宗门家族、关系网 |
| `characters.md` | 人物设定（主角、配角、反派、女主） |
| `plot-outline.md` | 三层规划：长期方向 + 中期规划 + 短期详细剧情 |

- **全部不存在**：AI 简要介绍协作流程（阶段一 → 阶段二），然后从阶段一开始。
- **部分存在**：AI 读取已有文件，列出当前进度，询问人要继续推进还是修改已有内容。
- **全部存在**：AI 读取全部文件，询问人是修改规划还是已经准备进入写作阶段（提醒切换到 xuanhuan-writing skill）。

## 三、阶段一：世界观与设定构建

### 流程概述

逐领域提问 → 迭代追问直到无疑问 → 整理定稿 → 人审阅通过 → 进入下一领域 → 全部领域通过后进入阶段二。

### 第一步：逐领域提问

AI 按以下领域，**每次只推进一个领域**，不可一次性跨领域堆砌问题。每个领域先提若干核心问题，根据人的回答进一步追问、细化，直到该领域没有遗留疑问。

#### 领域 1：宇宙与地理
- 世界叫什么？有多大？几个大陆/界域？
- 地形地貌特点？有什么特殊区域（禁地、秘境、古战场）？
- 凡人与修仙者的空间关系（凡人国度/修仙界/飞升后的世界）？

#### 领域 2：历史与种族
- 有哪些智慧种族？人族地位如何？
- 世界有没有重大历史事件？远古时代发生了什么？
- 有没有创世传说或上古大战的背景？

#### 领域 3：修炼体系（核心）

这是玄幻小说的骨架，需要充分细化：

- **修炼原理**：吸收灵气？感悟法则？血脉觉醒？还是其他？
- **境界划分**：从凡人到大圆满各叫什么？几个大境界？每个大境界分几个小境界？AI 可提供常见模板供选择（如：炼气→筑基→金丹→元婴→化神→渡劫→大乘），也鼓励自创。
- **每个境界的特征**：寿元、战力天花板、突破条件、突破失败的代价
- **功法体系**：功法分几等（如天地玄黄）？不同等级的功法差距有多大？功法的来源（宗门传承/秘境获取/自创）？
- **辅助体系**：丹药（分类与等级）、法宝（分类与等级）、阵法、符箓等。哪些必备，哪些可选？
- **修炼路径的多样性**：是否有不同流派（剑修/体修/法修/丹修等）？主角走什么路线？

AI 提问时应注意：
- 提供常见模板和选项供人选择，降低回答负担
- 如果发现前后矛盾（如境界设置和战力描述不匹配），主动指出并确认
- 讨论充分后，说"这个领域我觉得已经够了"，然后进入下一个

#### 领域 4：势力分布
- 最顶级的势力有哪些（宗门/家族/皇朝/圣地/商会）？
- 势力之间的核心关系（敌对/联盟/制衡/吞并）？
- 正邪如何划分？有没有中间地带？
- 散修的生存空间如何？
- 主角初始所处的势力环境？

#### 领域 5：人物设定
- **主角**：姓名、出身背景、初始处境、性格基调、金手指/特殊天赋（如有）、成长弧线方向
- **女主**：姓名、出身背景、性格特征、与主角的相遇方式、独立故事线
- **重要配角**（至少 3-5 个）：与主角的关系、各自的性格和动机
- **主要反派**（至少 2-3 个）：动机和目标、与主角冲突的根源

#### 领域 6：主角成长路线
- 起点：主角从什么状态开始（凡人/废材/重生/穿越）？
- 成长节奏：前期快速升级 / 稳步推进 / 厚积薄发？
- 金手指的形式：重生记忆/特殊体质/神秘师傅/至宝/血脉？
- 核心冲突：主角最终要面对什么（灭世危机/复仇/守护/揭秘）？

### 第二步：查漏补缺

全部领域覆盖完毕后，AI 主动反思：
- 有没有遗漏的重要设定？
- 有没有潜在的前后矛盾（如："你说主角出身寒门，但后来又说他是古老世家的后人，这两者之间是什么关系？"）？
- 有没有关键设定过于模糊，需要在写文之前先补清楚？

将发现的问题列出，逐一和人确认。

### 第三步：整理定稿

AI 将讨论结果整理为文件，每次提交一个文件供人审阅：

1. 先写 `world-building.md`
2. 再写 `cultivation-system.md`
3. 再写 `factions.md`
4. 最后写 `characters.md`

每个文件提交后，人可以选择：
- "通过" → 该文件定稿，AI 提交下一个
- "这里要改/补充" → AI 修改后重新提交
- "等一下，我有新的想法" → 回到对应领域重新讨论

**人必须明确确认全部 4 个文件通过后，AI 才能进入阶段二。**

## 四、阶段二：剧情规划

### 流程概述

长期方向 → 中期规划 → 短期详细剧情，三层递进。全部写入 `plot-outline.md`。

### 第一步：长期方向（全文骨架）

AI 基于已通过的世界观设定，提出全文的长期方向：

- 主线故事的核心驱动力（复仇/守护/追求巅峰/揭秘真相/…）
- 主角的终极目标
- 全文大致分为几个大篇章（如：凡界篇 → 灵界篇 → 仙界篇 → 混沌篇）
- 每个大篇章的核心冲突和结局大致方向
- 女主线的整体走向

**长期方向只定大方向，不写死具体情节。** 使用"可能"、"预计"、"方向是"等柔性措辞。

人审阅确认后，进入下一步。

### 第二步：中期规划（几十到上百章）

AI 基于长期方向，为第一个大篇章制定中期规划：

- 预计章数范围（如 50-80 章）
- 划分若干剧情弧（如：入门处境 → 初露锋芒 → 小有名气 → 危机降临 → 突破崛起）
- 每个剧情弧的核心冲突、关键转折、主角成长节点
- 主要配角和反派的出场时机和作用
- 女主线的节奏和推进节点

人审阅确认后，进入下一步。

### 第三步：短期详细规划（10+ 章）

AI 基于中期规划，制定短期详细剧情（至少覆盖接下来 10 章以上）：

- 每章的核心事件（1-3 句话概括，包含：本章发生什么、推进了什么、结尾落在哪个悬念或爽点上）
- 10+ 章整体的起承转合
- 关键爽点/高潮点的分布（不能太密也不能太稀）
- 人物关系的推进节点
- 伏笔的埋设计划和预计回收时机

人审阅确认后，短期规划定稿。

### 第四步：交接提示

所有规划完成后，AI 提醒人：

> 规划阶段已完成。下一步可以切换到 **xuanhuan-writing** skill 开始写正文。如果你想对规划做调整，随时可以回来找我。

## 五、规划修改与联动调整

人在任何阶段（包括已经进入写作阶段后回来）要求修改设定或规划时：

1. AI 先理解修改的具体内容
2. AI 检查该修改是否影响其他设定文件或规划层级
3. 向人汇报影响范围：
   - "这个修改影响了 A、B。需要我仅修改这一处（不联动），还是同步调整受影响的 X 和 Y？"
4. 人决定修改范围后，AI 执行修改并更新全部受影响的文件

## 六、文件约定

所有文件位于当前工作目录下。

| 文件 | 内容 | 更新时机 |
|------|------|----------|
| `world-building.md` | 宇宙地理、历史神话、种族文明 | 阶段一定稿时创建；后续修改时更新 |
| `cultivation-system.md` | 修炼境界、功法、丹药、法宝、阵法 | 同上 |
| `factions.md` | 势力分布、宗门家族、关系网 | 同上 |
| `characters.md` | 人物设定（主角、配角、反派、女主） | 同上 |
| `plot-outline.md` | 长期方向 + 中期规划 + 短期详细剧情 | 阶段二定稿时创建；后续修改或推进时更新 |

### 文件格式要求

- 统一使用 markdown
- 层级清晰，用标题分隔
- 关键信息用加粗或列表突出
- 修炼境界建议用表格呈现（境界名/小境界/寿元/特征）
